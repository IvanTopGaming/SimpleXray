SimpleXray adalah klien Xray-core untuk Android 10 dan versi lebih baru.

• Impor server dan langganan atau masukkan parameter koneksi secara manual.
• VLESS, VMess, Trojan, Shadowsocks/SS2022, SOCKS, HTTP, WireGuard dan Hysteria 2.
• Aturan domain, IP, GeoSite dan GeoIP dengan pilihan server untuk setiap blok perutean.
• DNS, FakeIP dan SplitDNS.
• Impor dan ekspor preset perutean melalui papan klip.
• Pemilihan aplikasi untuk VPN serta proxy SOCKS/HTTP lokal.
• JSON profil, penggantian konfigurasi dan log inti.
• Kecepatan, jumlah lalu lintas dan tombol putus koneksi di notifikasi.
• Opsi koneksi otomatis setelah perangkat dimulai ulang.

Kode sumber dan rilis: https://github.com/IvanTopGaming/SimpleXray
