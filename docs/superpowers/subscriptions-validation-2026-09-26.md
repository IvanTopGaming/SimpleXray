# Проверка подписок — 2026-09-26

Проверены изменения `15f7536` на Android 15 / API 35, AVD `simplexray`,
x86_64, с KVM. Использована debug-сборка 1.10.17 и предоставленная
пользователем подписка. URL и параметры доступа в отчёт не включены.

## Исправления

- Обновление выбранного сервера подписки перезапускает активный Xray.
- Удаление выбранного сервера очищает выбор и останавливает VPN.
- Пустой выбор сохраняется после перезапуска приложения; первый конфиг
  больше не выбирается автоматически.
- `PrefsProvider` удаляет значение при передаче `null`.
- Удаление другого ручного конфига сохраняет текущий выбор.
- Обновление списка конфигов согласовано с изменениями подписок через mutex.
- В native-сборке включена архитектура x86_64 наряду с arm64-v8a.

## Выполненные проверки

- `bash gradlew :app:assembleDebug --offline --console=plain` — успешно.
- Установка x86_64 APK поверх существующего приложения — успешно.
- Добавление подписки, загрузка трёх серверов, группировка, количество и
  время обновления в интерфейсе — проверены.
- У серверов подписки отсутствует отдельная кнопка удаления; у ручных есть.
- Подключение: HTTPS-запрос через SOCKS Xray вернул HTTP 204.
- Обновление активной подписки: PID Xray изменился с 6388 на 6460,
  журнал зафиксировал `RELOAD_CONFIG`; после перезапуска HTTPS снова вернул 204.
- Удаление выбранной временной подписки `Validation`: её файлы удалены,
  процесс Xray остановлен, выбор пустой и после полного перезапуска приложения.
  Основная подписка и её три файла сохранились.
- Импорт из Android-буфера VMess, Shadowsocks и Trojan: созданы JSON-конфиги
  с соответствующими outbound-протоколами. Первоначальная обрезанная строка
  VMess была ошибкой ввода через ADB; повтор с проверенной длиной прошёл.
- Удаление трёх временных ручных конфигов через интерфейс: выбранный сервер
  основной подписки и PID работающего Xray сохранились.
- Проверка diff отдельным ревьюером: блокирующие замечания исправлены.
- `git diff --check` — успешно.

## Пока не подтверждено

- Исчезновение выбранного сервера именно из ответа refresh, отдельно от
  удаления всей подписки. Обработчик общий, но отдельный сценарий не воспроизведён.
- Ошибка refresh существующей непустой подписки с сохранением её реестра,
  файлов и работающего процесса. Выключение Wi-Fi эмулятора не оборвало
  действующее соединение: refresh успешно завершился. Попытка временной
  подмены URL через `adb shell content update` была отклонена командой;
  чтением provider подтверждено, что исходный реестр остался прежним.
- Физическое Android-устройство не использовалось.

Временная подписка и три тестовых ручных конфига удалены через приложение.
Wi-Fi эмулятора включён. Основная подписка сохранена. Автотесты не добавлялись
согласно ограничению существующего плана. Задача 10 остаётся частично выполненной.
