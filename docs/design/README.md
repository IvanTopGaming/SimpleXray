# SimpleXray: веб-макет

`lab.html` — интерактивный каркас для совместной проработки дизайна.
Android-приложение и VPN в нём не запускаются; реальные подписки не используются.

Четыре вкладки: Главная, Серверы, Подписки, Настройки. Роутинг пока вложен
в настройки; это предварительное предложение для обсуждения. На главной
намечены выбранный сервер и неактивная кнопка подключения.

Возможности: три размера экрана, светлый/тёмный фон, сетка и одна координатная метка.
Метка ставится кнопкой «Указать место» и кликом по экрану. Содержимое будущего
элемента обсуждается в чате. При перезагрузке состояние холста сбрасывается.

Для самостоятельного локального просмотра из корня репозитория:

```sh
python -m http.server 5173 --bind 127.0.0.1 --directory docs/design
```

Открыть `http://localhost:5173/lab.html`.

В совместной сессии используется Superpowers Visual Companion: HTML копируется
в каталог текущего экрана, а изменения и клики передаются через его сервер.
Файлы сессии, URL-ключ и события хранятся в игнорируемой `.superpowers/`.
Самостоятельный статический просмотр не отправляет координаты агенту.
